# 长连接库 FFI 集成计划

## 概述

创建一个完整的模拟长连接库系统，包含 C++ 端的委托模式实现、Worker 线程、定时器，以及 Dart FFI 的集成和 UI 展示。

## C++ 端实现

### 1. LongLinkDelegate 接口（native/src/long_link_delegate.h）

定义委托接口，包含以下回调方法：

- `onConnected()` - 连接成功回调
- `onConnectFailed(const char* error)` - 连接失败回调
- `onDataReceived(const char* data, int length)` - 接收数据回调
- `onDisconnected()` - 断开连接回调

### 2. LongLinkManager 主类（native/src/long_link_manager.h/cpp）

核心管理类，功能包括：

- `setDelegate(LongLinkDelegate* delegate)` - 设置委托对象
- `startConnection(const char* url)` - 开始连接
- `stopConnection()` - 停止连接
- `sendData(const char* data)` - 发送数据
- 维护连接状态（已连接、未连接、连接中）

### 3. LongLinkWorker 工作线程（native/src/long_link_worker.h/cpp）

模拟异步工作线程，实现：

- 使用 C++ `std::thread` 创建独立线程
- 启动后自动调用 `onConnected()`
- 使用定时器（每 5 秒）调用 `onDataReceived()`
- 模拟接收服务器推送的数据（如心跳、消息等）
- 线程安全的启动和停止机制

### 4. FFI 导出接口（native/src/long_link.h/cpp）

提供 C 风格的 FFI 接口：

```cpp
// 创建和销毁
void* create_long_link_manager();
void destroy_long_link_manager(void* manager);

// 设置 Dart 回调
void set_long_link_callbacks(
    void* manager,
    void (*on_connected)(),
    void (*on_connect_failed)(const char*),
    void (*on_data_received)(const char*, int),
    void (*on_disconnected)()
);

// 控制方法
void start_connection(void* manager, const char* url);
void stop_connection(void* manager);
void send_data(void* manager, const char* data);
const char* get_connection_status(void* manager);
```

## Dart 端实现

### 5. FFI 类型定义（lib/long_link_types.dart）

定义所有 FFI 类型：

- C 函数签名（Native）
- Dart 函数签名（Dart）
- 回调函数类型
- 状态枚举

### 6. LongLinkBridge（lib/long_link_bridge.dart）

Dart FFI 桥接层：

- 加载原生库
- 绑定所有 C 函数
- 封装 Dart 回调为 NativeCallable
- 提供 Dart 友好的 API
- 管理资源生命周期

### 7. LongLinkController（lib/pages/long_link_test/long_link_controller.dart）

GetX 控制器，管理：

- 连接状态（响应式）
- 接收的数据列表（响应式）
- 连接/断开操作
- 发送数据功能
- 错误处理

### 8. LongLinkTestPage（lib/pages/long_link_test/long_link_test_page.dart）

UI 页面，展示：

- 服务器地址输入框
- 连接状态指示器
- 连接/断开按钮
- 发送消息输入框和按钮
- 实时数据接收列表（自动滚动）
- 连接时长显示

## 技术要点

### C++ 特性

1. **多线程编程**：使用 `<thread>`, `<mutex>`, `<condition_variable>`
2. **定时器实现**：使用 `std::this_thread::sleep_for`
3. **委托模式**：纯虚接口 + 实现类
4. **RAII 资源管理**：智能指针、析构函数
5. **线程安全**：互斥锁保护共享数据

### Dart FFI 特性

1. **异步回调**：`NativeCallable.listener` 处理 C++ 回调
2. **内存管理**：正确释放 C++ 对象和字符串
3. **字符串传递**：`toNativeUtf8()` 和 `toDartString()`
4. **状态同步**：回调中更新 GetX 响应式变量

### 模拟数据场景

Worker 定时推送的数据类型：

- 心跳包：`{"type": "heartbeat", "timestamp": 1234567890}`
- 消息通知：`{"type": "message", "content": "New message"}`
- 状态更新：`{"type": "status", "online": 100}`
- 模拟计数器：递增的消息编号

## 预期效果

1. **连接流程**：

   - 点击"连接" → Worker 启动 → 1秒后回调 `onConnected()`
   - UI 显示"已连接"状态

2. **数据接收**：

   - 每 5 秒自动接收一条模拟数据
   - 数据以 JSON 格式展示在列表中
   - 列表自动滚动到最新消息

3. **发送数据**：

   - 输入消息并发送
   - 显示"已发送"反馈

4. **断开连接**：

   - 点击"断开" → Worker 停止 → 回调 `onDisconnected()`
   - UI 显示"未连接"状态

5. **错误处理**：

   - 模拟连接失败场景
   - 显示错误信息
